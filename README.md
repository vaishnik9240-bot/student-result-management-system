# Student Result Management System

## About the Project

This is a Python-based Student Result Management System.
It helps manage student marks, calculate total marks,
percentage, and grade.

## Features

- Add student
- Enter student marks
- Calculate total
- Calculate percentage
- Calculate grade
- Search student
- Delete student
- Display all results

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download this project.
3. Open the project folder in Command Prompt.
4. Run:

python student_result.py
